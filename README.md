# CodeGuessr

[![CI](https://github.com/MysterionRise/code-guesser/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/MysterionRise/code-guesser/actions/workflows/ci.yml)

CodeGuessr is “GeoGuessr for code”: read an unfamiliar excerpt of real
open-source code, reveal clues if you need them, and guess.

## What you play

The root route is a deck chooser. Each deck has five rounds, prepared from real
public code by one verified run on 2026-10-11
([evidence](docs/review/evidence/2026-10-11-three-deck-live-run.md)):

| Deck | You see | You pick from | Source |
| --- | --- | --- | --- |
| Which project? | changed lines from a real commit | four `owner/name` repositories | GitHub commit search |
| Which language? | a file excerpt | four languages | The Stack v2 metadata, Software Heritage blobs |
| AI credit | changed lines from a real commit | credited or not | GitHub commit search; the answer is whether the commit message records an AI co-author credit |

`/?deck=project`, `/?deck=language` and `/?deck=ai` open a deck directly. The
AI deck is being replaced by a "Before or after?" deck; see the
[state review](docs/review/2026-10-11-codeguessr-state-review.md).

The real-data PoC is localhost-only, automatically prepared, unreviewed, and
not meant for public players.

## Play locally

Prerequisites: Node.js `20.18.0` and pnpm `9.15.9`.

```bash
pnpm install --frozen-lockfile
pnpm --filter @codeguessr/game dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000). The root route reads
`apps/game/src/demo/generated/local-real-rounds.json`, checks it against the
pinned hash in `apps/game/src/demo/local-real-experiment.pin.server.ts`, and
makes no network requests while you play. If the artifact is missing, has the
wrong hash, or is from an older format, the page says so and offers no rounds.

For a production-mode local run:

```bash
pnpm --filter @codeguessr/game build
pnpm --filter @codeguessr/game start
```

### Recording the demo

`pnpm demo:record` starts a dev server on port 3100, plays scripted scenes in
headless Chromium at a 390x844 viewport with caption overlays, and encodes one
GIF per deck, a full-run GIF, and an MP4 into `docs/media/`.

| Variable | Effect |
| --- | --- |
| `DEMO_BASE_URL` | Record a server that is already running |
| `DEMO_SCENES` | Comma-separated scene ids to record a subset |
| `DEMO_ANSWERS` | Five comma-separated radio indexes for the full run |

It needs `ffmpeg` on the `PATH` and the Playwright Chromium build
(`pnpm exec playwright install chromium`). Raw screencasts land in the ignored
`docs/media/.work/` directory.

## Preparing rounds

`pnpm prepare:poc` crawls before play and freezes the result:

1. Read The Stack v2 metadata. The worker streams one parquet row group per
   language (Python, TypeScript, Go, Rust, Ruby) and screens the rows.
2. Search GitHub commits with the profile's queries, then bind each candidate's
   lineage, licence, and recorded author.
3. Fetch only the selected blobs from Software Heritage and revalidate them
   against GitHub.
4. Compose the three decks and publish the artifact and its run report
   atomically.

The profile `ops/poc/profiles/local-real-rounds.v2.json` holds the queries and
ceilings: 600 requests, 96 MiB of Stack metadata, and 3 pages or 300 results per
query. The Python workers enforce the same limits in-process and report their
counts back to the preparer.

### Credentials

Provide credentials only through environment variables or provider-standard
credential stores. Never put them in repository files or saved commands.

| Input | Requirement |
| --- | --- |
| `HF_TOKEN` | Required, for the gated `bigcode/the-stack-v2` dataset. The worker ignores implicit token files, so export it explicitly. |
| `GITHUB_TOKEN` | Required in practice. A run makes several hundred GitHub requests, and the unauthenticated quota is 60 per hour. |
| `STACK_V2_ACKNOWLEDGED_USABLE_REVISION` | Required non-secret acknowledgement: `e565caa3a78c2423bd374333a472b049eb090e47`. |
| Software Heritage | No credential needed; the content bucket serves selected objects anonymously. |

```bash
HF_TOKEN="$(cat ~/.cache/huggingface/token)" \
GITHUB_TOKEN="$(gh auth token)" \
STACK_V2_ACKNOWLEDGED_USABLE_REVISION=e565caa3a78c2423bd374333a472b049eb090e47 \
pnpm prepare:poc
```

Outputs:

- `apps/game/src/demo/generated/local-real-rounds.json` (committed)
- `ops/poc/stack/tmp/local-experiment-run.json` (ignored)

After a successful run, verify the artifact and update the pinned hash before
the root route will accept it.

A failed run logs `PREPARATION_STAGE_FAILED <stage> <reason-code> <status-class>`
and `PREPARATION_FAILURE_SITE <function>@<file>`. When selection fails it also
logs `PREPARATION_COUNTS` and `PREPARATION_REJECTIONS` aggregates. It never logs
a body, URL, identity, or credential.

## Guardrails

- Localhost only; no deployment and no public players.
- Public open-source code only, with licence and recorded-author data.
- Bounded, selective reads only. Never download a whole dataset, a whole
  language shard, or a repository archive.
- Credentials come only from standard stores and are never logged or
  committed.
- Gameplay never touches the network.
- Malformed provider data fails closed. Transient errors may be retried within
  the request budget.

`pnpm exec playwright install chromium`.
