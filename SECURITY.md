# Security policy

Report a vulnerability privately, through GitHub's private vulnerability
reporting (the repository's Security tab, "Report a vulnerability"):
<https://github.com/MysterionRise/code-guesser/security/advisories/new>.
Do not open a public issue or pull request for it.

Say what you found, where, and how to reproduce it. Put no token, key, or
personal data in the report. In scope: the game server (`apps/game`), its
container image, and the preparation pipeline (`ops/`). The game is built from
`main`, so a fix lands there.
