# CodeGuessr v1.1.0

CodeGuessr is "GeoGuessr for code": read an excerpt of real open-source code, buy a clue if you need one, and guess
where it came from or what it does. v1.1 is ready for public play and still served locally (milestone v1.1,
checklist #174). Everything anonymous play on one instance of the owner's own server needs is merged and tested,
beside duel challenge links, bigger decks, and a pre-launch pass that measured, for the first time, whether the
game is fun.

The launch itself, a server and day 0, is not part of this release. The owner deferred the server on 2026-11-04,
so launch has its own milestone (Launch, #100). The [2026-11-10 review](../review/2026-11-10-next-steps-review.md)
recommends that it follow the data-quality release the fun pass asked for (milestone v1.2).

### Duels

A finished game of a seeded deal or of today's five becomes a challenge link; a friend's finished game of it a
result link (#173; #177, #196, #199, #203). Tokens are encrypted and short-lived, names live only in the link's
fragment, and the friend sees each of the challenger's rounds once their own is locked. Events record a duel's
creation and outcome under `origin: duel`, outside the experiment's comparisons.

### The fun pass

Agent playtest run 3 (`docs/review/evidence/2026-11-02-agent-playtest-run-3-fun.md`) put fun first for the first
time: eight personas (a returning player, a phone commuter, a duel pair, a streak chaser, a learner, a code-blind
calibration instrument, a red team, and a keyboard player) and five judges, against a nine-line release bar. The
protocol is checked in under `ops/playtest/` (personas, judges, a run sheet, an aggregator), and the driver now
pins deals, opens duel and share links, plays at phone width, fakes the clock, passes links through a clipboard,
and plays blind (#223, #224).

What changed because of it:

- **The end of a game pays off** (#226, #244): "New best 4,300, up from 3,800 · Streak 3 games, your longest · Day
  streak 2", "First score on this deck", and "Streak of 3 ends"; a streak line under the header during play ("2
  more right keeps your streak", "Streak kept", "Streak over"); the day streak by the score on today's five, which
  now names itself in the game.
- **Rounds read fresh** (#226, #242, #243): each round arrives with its own transition; no verdict phrase repeats
  in a game; the reveal's shared sentences show once a game under "Why this is the answer" and "Easy to confuse:";
  the family decks (exercise, framework, algorithm) deal each option family at most once a game; a mixed series
  walks each deck's order so games of one seed never repeat a round.
- **Duels show the stakes** (#244): "You 2,800 · Ana 1,800" after each lock, "First time on these rounds", "Can
  you match it?" at a perfect score, a "Challenge back" cue on the result page, and a rematch link that says what it
  deals.
- **Plainer controls** (#242): the hint button carries its cost, the cost line and the captions that restated the
  prompt are gone, and no em-dashes.
- **Generative UI** (#227, #245): `OPENROUTER_REASONING` and a model and reasoning per design
  (`OPENROUTER_MODEL_HOST`, `OPENROUTER_REASONING_HOST`, and so on), since OpenRouter's Claude Sonnet 5.5 refuses
  reasoning off; the host offers a hint once a round and retries an empty reply; a visualizer page that dies on load
  falls back with one "Try again" (#238).
- **Phone** (#245): the finished game's table never breaks a word or a number, explainer tables scroll inside their
  card, and lines wrap by default.
- **Robustness tests** (#225): axe on layered rounds after both hints and on every theme, a restart mid-game in a
  browser, the report command end to end, and the summary table's structure in every theme.

The #120 pilot compared Claude Haiku and Claude Sonnet explainers on the same rounds: level on accuracy for the
catalog, composer, and visualizer at 14 to 18 times the cost, so they keep Haiku; the Sonnet host answered every
after-lock question where the Haiku host answered nothing on 3 of 7, so the host is the design to set apart. The
production setting is the owner's.

### After the fun pass

- **Anthropic's own API as a second provider** (#246): generative UI can call Anthropic's Messages API instead of
  OpenRouter. `ANTHROPIC_API_KEY` alone, or `GENUI_PROVIDER=anthropic`, sends the same guarded request through the
  AI SDK's Anthropic provider; `ANTHROPIC_MODEL` (default `claude-haiku-5-5`), `ANTHROPIC_REASONING`, and the
  per-design settings mirror OpenRouter's. A public server holds `ANTHROPIC_BASE_URL` to Anthropic's, and the
  privacy page says what Anthropic keeps. Its first live check rendered every design on the first try
  (`docs/review/evidence/2026-11-03-genui-anthropic-live-check.md`).
- **Security updates for the Stack worker** (#251): the 28 Dependabot alerts on the worker's `uv.lock` were taken
  by hand (datasets 5.0.1, certifi, urllib3, aiohttp, fsspec, filelock, multidict, yarl), since the preparer pins
  that file's hash. See "Upgrading" for what it means for a recorded journal.
- **The next steps review** (#254, `docs/review/2026-11-10-next-steps-review.md`): four reviewer agents read the
  milestones, the pull requests, and every open issue, and a targeted playtest, run 3b, covered what run 3 left
  untested (#241). The review proposes the data-quality release, v1.2, and lists the owner's open decisions.

## Upgrading

- Public mode needs `CODEGUESSR_PUBLIC=1`, `CODEGUESSR_SESSION_SECRET` (32+ characters), an https
  `CODEGUESSR_PUBLIC_ORIGIN`, absolute `CODEGUESSR_STATE_DIR` and `EXPERIMENT_EVENTS_DIR`, and
  `CODEGUESSR_CLIENT_IP_HEADER`; `docs/deploy.md` is the runbook, and `pnpm test:deploy` checks the boot.
- Generative UI: `OPENROUTER_REASONING` (`off` by default; `low`, `medium`, `high` for a model whose endpoint
  requires reasoning) and `OPENROUTER_MODEL_<DESIGN>` / `OPENROUTER_REASONING_<DESIGN>` per design; or Anthropic's
  own API with `ANTHROPIC_API_KEY` and the same settings under `ANTHROPIC_` (`GENUI_PROVIDER` picks when both keys
  are set).
- The artifact is the 2026-10-26 rebuild of the v7 data run under the round fixes of #200 (`847e7512…`, #214),
  pinned in `local-real-experiment.pin.server.ts`. It replaced the v7 data run's own `81f31057…`. Local records
  are keyed to it, so a new artifact starts them over.
- Rebuilding the artifact offline: recorded worker outputs are keyed to the worker's code and its lock, which
  moved in #251. A journal recorded before 2026-11-04 fails `pnpm prepare:poc --offline` with `JOURNAL_MISS` at
  `STACK_METADATA` until one `--resume` records them again. A resume on a later day also changes the artifact's
  hash, through two live counters in Hugging Face's dataset-info response, though no round changes (#252): keep
  the journal's first entry from the earlier run, and `--offline` then reproduces `847e7512…`.
- Seeded orders changed for the family decks (#243) and seeded mixed deals (#226): a challenge link made before
  those merges refuses with `DEAL_DRIFT`. Before launch day no change log entry is needed; after it, each
  player-visible change gets one in `ops/experiment/changes.json`.
- The playtest driver runs under `node --import tsx` (it imports the demo scenes' seeds).

## Known limits

- **Not launched.** The game is served on localhost only, and the deploy runbook has never run against a real
  server. Launch is the Launch milestone (#100, #170), with the production model per design (#120) and tests of an
  Anthropic-only server (#256) still open there.
- **Hints that state the answer** (#228, #229): without the code, a solver scores 5 of 5 after hint 1 on the
  algorithm, framework, and exercise decks, and hint 2 names the language's tell; fix's hint 1 rules out nothing,
  before-after is a coin toss without its commit message, output's hints eliminate rather than teach. Hint text is
  artifact data, for the next preparation run (v1.2); what a hint is for is the owner's decision first (#82).
- **Reveal sentences that fit any round** (#230, #231): the project deck's helpful signal and misleading frame on
  every round, name-function's helpful signal on 39 of 48 rounds, one wrong complexity sentence, one signal naming
  the word "the", and before-after commits whose message does not match the panes. Data, next run. Five rounds
  the review read should be refused or fixed there too (#257).
- **Question layers** cover the algorithm and language decks only; Marker hunt's prompts repeat (#240); nothing
  checks a trace against its code (#159). On unseen rounds the algorithm scaffold lifted a code-blind first guess
  from about chance to 7 of 12, a thin pass of the bar on a small sample, so its fairness stays the owner's
  decision (#160).
- **Explainers** still make mistakes on Haiku (1 in 100 claims wrong on the catalog, 3 in 100 on the composer);
  the host on Sonnet costs about $0.07 a game.
- **No real players yet.** Agents know most answers, so their fun is a direction, not a measurement; the design
  experiment (#106–#108) reads real play after launch.
- "Spot the vulnerable line" (#59) is built and left out of the profile, deferred for its cost in requests; "Which
  era?" (#60) is not built; practice mode (#64) and live duel rooms come later.
