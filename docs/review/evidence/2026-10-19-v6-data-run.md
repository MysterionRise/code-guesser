### Why the first replay missed

GitHub rate-limited requests late in the live run. The run's five retries were spent by then, so 13 requests were given
up (`RUN_RETRY_LIMIT`) and their candidates skipped. A rate limit asks for a retry and carries no failure of its own, so
the journal recorded nothing for those requests, and an offline replay could not follow the live run past the first of
them (a TodoMVC blob the framework deck reads).

The data-run PR fixes the gap: a rate limit the run could not retry is now journaled as an offline-only failure (a 429),
so an offline replay rejects the same candidate and a resumed run asks again (`ops/poc/prepare/runtime.ts`, tested in
`journal.test.ts`). For this run, the `--resume` fetched the 29 requests the journal lacked, which changed some later
rounds from the live run's; the published artifact is the resumed one, and both offline replays reproduce it.

## Checks on the artifact

- The leakage test (`packages/artifact/test/deck-leakage.test.ts`) passes on every deck. The three v6 leak tests that
  were expected failures on the v5 artifact now pass and are plain tests: project word overlap (#77), output
  transforms (#78), and before-after pane size (#75). The three #81 memory tests for family decks stay expected
  failures, as before.
- The fix deck's prose check flagged four code lines of one round (`sanic/app.py`): its window ends on a docstring
  opened under a `def`, which the test's heuristic read as the pane starting inside a docstring. The heuristic now reads
  a quote just under a `def` or `class` line as opening one.
- Parsing the artifact, twice as large as v5's, took about 1.1 s, enough that a cold dev server missed the browser
  tests' five-second waits. Nearly all of it was the containment check building a whole-word pattern for every
  protected value against every public text; it now rules out a value that is not even a substring first and compiles
  each pattern once, which brings the parse to about 0.4 s with the same results.
- Rejections the v6 rules made: `PROJECT_WORDS_IN_EXCERPT` 18, `PROJECT_NAME_IN_EXCERPT` 22, `LINEAGE_SIZE_UNBALANCED`
  34, `LINEAGE_PROSE_ONLY` 11, `DATA_ONLY_CONTENT` 6, `GENERATED_PATH` 1, `OUTPUT_IDEA_REPEATED` 3, `FIX_FILE_REPEATED` 3.
