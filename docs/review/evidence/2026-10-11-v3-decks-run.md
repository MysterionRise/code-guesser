## What the decks hold

- **Which project?** Ten rounds over twenty popular repositories, four per
  language. Every round of a language offers the same four, so each appears
  equally often:
  - Python: EasyOCR, PaddleHub, django, grpc
  - TypeScript: gatsby, nest, next.js, ant-design
  - Go: tidb, iris, kubernetes, gitea
  - Rust: nushell, rustlings, rust, tauri
  - Ruby: aws-doc-sdk-examples, sinatra, homebrew-core, spree

  The options show each repository's GitHub description. The hints are the
  file name, then the repository's approximate star events.
- **Which language?** Two rounds per language from ordinary repositories:
  - Each round offers its answer and three of the other four languages.
  - Each language is offered in exactly eight of the ten rounds.
  - The window starts past the import and package lines.
  - The hints name the excerpt's block structure, then a piece of syntax it
    contains.
- **Before or after?** Ten refactor commits from kubernetes, google,
  facebook, microsoft, and vercel. Each round shows the same stretch of one
  file before and after the commit. The later version is pane A in five
  rounds and pane B in five. The hints quote the commit subject, then the
  lines it removed and added.

The `deck-leakage` test runs against this artifact. Each solver that never
reads the code stays within chance plus ten points:

- **Same options:** remembers which option answered rounds with the same options.
- **Most frequent:** picks the option that appears most often.
- **Has a description:** picks an option because it has a description.
- **Always one pane:** always picks pane A, or always pane B.
