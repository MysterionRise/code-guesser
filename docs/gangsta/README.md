# Retired: the signed-Contract process

This folder is the historical record of how CodeGuessr was planned and governed
from July to October 2026: signed Contract revisions, execution plans,
checkpoints, reviews, and live-run evidence.

The process was retired on 2026-10-11. Nothing here gates current work:
queries, retries, ceilings, deck rules, and live preparation runs are ordinary
engineering changes now. The guardrails that still apply are in the top-level
`README.md` and `CLAUDE.md`, and the current review and roadmap are in
`docs/review/2026-10-11-codeguessr-state-review.md`.

Some code comments and content policies still link to evidence files here;
those links stay valid.
