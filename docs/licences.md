# Licences of the excerpts

Every round shows a short excerpt of open-source code under one of the licences that the profile allows
(`ops/poc/profiles/local-real-rounds.v7.json`, `licenses`): MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC,
and Python-2.0. The v7 artifact uses the first five. No round uses Python-2.0 yet.

This note sets out what each licence asks of a page that shows excerpts, and how the game meets it. It is a
reading of the licence texts, not legal advice. Its one open judgment call is Apache-2.0's NOTICE files, below.

## What the game does

- **The reveal:** every round's reveal names the file's author, the repository, and the licence by name and SPDX
  id. It links the file at the commit the excerpt was read at.
- **`/credits`** (#99), built from the committed artifact (`experiment.credits`):
  - lists every source file, grouped by licence, then repository;
  - links each repository's own licence file at that commit, which carries its copyright notice and the licence's
    terms;
  - links each licence's text on spdx.org;
  - says that excerpts are changed copies and that no project endorses the game.
- **Excerpts are changed copies:**
  - every excerpt is a window of its file;
  - some decks also remove comments and hide names as `mystery`, among them the algorithm, framework, and exercise
    decks;
  - the missing-line deck leaves a line out.
- **Credits never name their round.** A file's path often names its round's answer, so credits carry no round id,
  deck, order, or hash.

## What each licence asks

| Licence | Asks, for a copy or a substantial portion | How the game meets it |
| --- | --- | --- |
| MIT | The copyright notice and the permission notice, included in all copies or substantial portions. | Reveal and credits name the author and licence; credits link the repository's licence file at the commit, which holds both notices. |
| ISC | The copyright notice and the permission notice, appearing in all copies. | As MIT. |
| BSD-2-Clause | Redistributed source keeps the copyright notice, the list of conditions, and the disclaimer. | As MIT: the linked licence file holds all three. |
| BSD-3-Clause | As BSD-2-Clause. Also, the names of the holder and contributors may not endorse or promote derived products without permission. | As BSD-2-Clause. The credits page says no project endorses CodeGuessr. A project round names repositories as answer options, which is a fact about the code, not an endorsement. |
| Apache-2.0 | (a) A copy of the licence. (b) Modified files carry prominent notices that they were changed. (c) Copyright, patent, trademark, and attribution notices kept. (d) If the work has a NOTICE file, its attribution notices appear in a NOTICE file, the documentation, or "a display generated by the Derivative Works, if and wherever such third-party notices normally appear". | (a) The credits page links the licence text and the repository's licence file. (b) The credits page says excerpts are changed copies; reveals and credits name each file. (c) Excerpts keep no notices themselves, since comments are often cut; the linked licence file carries them. (d) See below. |
| Python-2.0 | The PSF licence agreement and its copyright notice kept in any derivative version, and a brief summary of the changes made. | No round uses it yet. Before one does, credits should state the change summary per file (a window, comments removed, names masked) and link the PSF notice. |

## The judgment call: Apache-2.0 NOTICE files

Section 4(d) applies only to a work that ships a `NOTICE` file. The preparer does not record whether an Apache-2.0
repository has one: it reads the licence file at the pinned commit and nothing else at the root. Two readings
are possible:

1. **Excerpts of a few lines are not "Derivative Works" in 4(d)'s sense**, or they are too small to carry the
   NOTICE. Linking the repository at the commit, where the NOTICE sits beside the licence, is enough. That is
   the game's practice today.
2. **The conservative reading:** wherever an Apache-2.0 repository has a `NOTICE` file, the credits page shows its
   attribution notices, or at least links the file. That would take one bounded read per Apache-2.0 repository at
   preparation time: one tree listing, plus the file where it exists. The NOTICE's URL would go in the source
   record, and the parser would hold it to the same commit as the licence file. The v7 artifact has 56
   Apache-2.0 files, from 52 repositories.

This is the owner's call. Reading 2 needs a preparer change and a data run, under the existing request budget.
